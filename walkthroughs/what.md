# What Task Beacon is

Task Beacon is a **sidebar board** for work you already own. The center is a wiki folder of task files. It does not replace your tracker, your notes app, or your agent.

Three owners. Same epic → task shape Jira uses — you do not have to *use* Jira.

| You see | Whose work | Where it comes from |
|---------|------------|---------------------|
| **Official** | Company / team | Wiki files tagged `official`. Jira only if you set it up. |
| **Private** | You | Wiki files tagged `private` |
| **Agent** | An agent, or recurring automation | Wiki files tagged `agent-task` / `agent-cron`. Live cron only if Hermes is installed. |

Nothing is required on first launch. Sample tasks are already in the tree so you can click around.

Skip anything that does not match how you work. No Jira, no Hermes, no cloud AI — a wiki folder is enough.
